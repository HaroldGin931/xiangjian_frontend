# 乡建独立前端

面向 Rice 本地链路的独立视觉验收项目。应用使用 TanStack Start 管理路由与服务端接口调用，使用 Astryx 组件与主题作为基础设计层，不依赖 Next.js。

## 本地运行

先启动已有的 Rice 本地栈（默认网关为 `http://localhost:19006`），再运行：

```bash
npx --yes pnpm@10.17.1 install
npm run dev
```

前端默认地址为 `http://127.0.0.1:19007`。如果后端不在默认地址，可通过 `XIANGJIAN_BACKEND_URL` 指定。

附件相对地址通过当前站点的 `/api/...` 路径访问；提供前端的入口需将该路径转发至网关。
直接运行 Vite 时，目前没有配置该代理。

## 分支用途

- `feat/task-v1`：日常开发分支。
- `demo-wamo-social`：演示部署分支。

核对演示版本时，以 `origin/demo-wamo-social` 为比较基准；核对开发分支是否已上传时，
以 `origin/feat/task-v1` 为基准。

## 当前边界

- 已接入：Rice 登录、注册、找回密码、当前用户档案与账号安全、附件头像、Task V1 用户流程；Post Cache 帖子列表与搜索、PDS 文字帖发布、AT Protocol 通知列表。
- 帖子分类由 PDS 记录中的 `xjdaoCategory` 决定；没有分类字段的历史记录视为普通帖子。正文里的 `#Tag` 只用于搜索，点击后进入搜索页，不改变内容分类。
- 测试阶段发布入口提供帖子、活动和任务；商品发布/筛选及尚未实现的占位入口已隐藏，历史商品内容仍保留读取兼容。发布活动复用普通帖子接口，截止时间、地点和参与条件以结构化文本随帖保存，均可选。
- 活动参与复用现有评论接口，写入一条“参与活动”回复。发布帖或评论后先用 PDS 返回的真实记录更新当前页面缓存并立即返回；后续正常读取再由 Post Cache 结果校准，不再阻塞等待索引同步。
- Task V1 以 Rice 为业务读写来源，支持所有已登录用户发布任务，以及草稿、申请、任命、提交结果、认可/不认可、取消与失效。奖励可为 0；正数奖励由发布者出资，发布时冻结、完成时发放、取消或失效时退回。节点稻米池暂不接入。
- 搜索支持“全部 / 帖子 / 任务”，按发布时间合并结果，每批展示 10 条并向下滚动加载；后端原有页码式 API 继续保留。
- 私信不在当前产品范围内；通知保留为一级入口，并直接读取当前账号的真实通知。
- 项目不预填账号、不生成帖子，页面只展示本地后端返回的真实数据。
