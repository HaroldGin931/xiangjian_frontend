# 乡建前端

当前实现从已上传 V11 提交 `5b40a14` 继续实现已确认的最小原型。使用 TanStack Start、Astryx 与现有组件；普通帖子属于 PDS，任务、活动、社区和稻米属于 Rice。

## 本地运行

安装依赖：

```bash
npx --yes pnpm@10.17.1 install
```

先准备隔离 Rice/PDS 网关，再启动前端。本轮验收使用网关 19016、前端 19017：

```bash
XIANGJIAN_BACKEND_URL=http://127.0.0.1:19016 npm run dev -- --port 19017
```

访问 `http://localhost:19017`，登录统一使用 `localhost`。不指定参数时仍使用旧默认网关 19006、前端 19007；请按需要选择，避免混用两套测试数据。Vite 将 `/api/attachments` 与固定的 `/pds/xrpc/com.atproto.sync.getBlob` 转发到 `XIANGJIAN_BACKEND_URL`，分别读取 Rice 附件与 PDS 原图。其他 Rice/PDS 请求由 TanStack 服务端函数转发，两套令牌分别用于对应服务。

## 当前实现范围

- **全局搜索**：帖子、任务、活动、社区、用户五组结果默认展开，可独立收起；新关键词恢复展开，空结果保留提示。帖子使用 Post Cache，其他四类读取 Rice；用户按昵称或账号搜索，点击打开个人主页浮窗。用户分页只返回公开资料，不搜索联系方式。

- **页面与发布**：广场、任务、活动、我的四个底栏入口；顶部全局搜索和通知。发布浮窗按所在页面默认选中发帖、发任务或发活动，切换类型保留各自输入。手机随视口收窄，桌面内容最大宽度 760px。
- **普通帖子**：读 Post Cache，使用 PDS 发布、回复及既有互动；在正文输入 `#话题`，不单列话题字段。发布结果直接使用 PDS 返回的真实记录更新缓存，后续由索引读取校准。重试复用本次帖子的记录键，避免网络响应丢失后重复创建。
- **正文与图片**：帖子、任务、活动共用选图预览、移除、列表首图、详情图片组和放大浮窗，最多四张，支持 JPEG/PNG/WebP/GIF。选择文件时只创建本地预览，保存或发布时才上传。帖子使用 PDS `uploadBlob` 和标准 `app.bsky.embed.images`；当前隔离 PDS 镜像单图上限为 1,000,000 bytes。任务/活动使用 Rice 附件，单图上限为 20 MiB；`attachment_ids` 与草稿正文一起保存，重新打开恢复顺序。部分上传失败会保留输入，重试复用已成功上传的文件。
- **单人任务**：只有所属社区的管理员可以发布；草稿包含交付要求、申请截止、交付截止与报酬。发布前保存服务端草稿，余额不足时可恢复继续编辑。申请、选定一人、提交成果、退回重交、一次验收并发放和任命前取消均调用 Rice。申请截止只停止新申请；执行逾期保留任务与冻结资金，并提供负责人入口。发布后核心约定锁定，保存后的草稿社区也保持固定。
- **我的任务**：合并本人发布、申请和承接的记录，管理员也能回访在其他社区参与的任务。候选选择显示“待审批”，成果待验收显示“审核中”；未入选归入已结束。
- **活动**：使用独立 `/api/events`，包括草稿、发布、申请、候选通过/拒绝/移除、取消及主办方确认结束。申请与通过人数分别显示；动作入口以服务端允许动作为准。免费与测试稻米活动共用候选审批流程，付费申请、未入选退款及结束结算由 Rice 原子处理；不再用普通帖和评论模拟活动报名。
- **社区**：社区身份显示本人所在社区和角色；联盟与治理进入节点目录，详情保留社区成员、本人申请结果、管理员待审批名单和社区动态入口。加入申请资料仅申请本人及管理员可见，不在公开社区进展中展示。
- **个人与稻米**：保留个人主页、编辑资料、头像、退出登录；显示真实可用余额、冻结余额、累计获得和分页明细，退款不重复计入累计获得。任务/活动的公开履历与本人私有申请记录分别读取。
- **通知**：合并 Rice 任务/活动/社区通知与既有 PDS 通知，点击进入相应详情。进入通知页面不会自动将全部记录标为已读，提供显式“全部已读”动作。

所有写操作均使用真实接口，无演示身份切换或模拟成功。本轮只用于隔离测试账号、测试稻米与测试记录；不开放真实成员资产。小队、邀请、管理员交接、任务任命后取消/换人/延期、商品和私信不在本次最小范围内。
